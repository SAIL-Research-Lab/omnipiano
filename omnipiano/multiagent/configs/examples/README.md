# Additional MARL examples

These launchable configurations are useful but are not part of the frozen
WinterWind SCHO 5 x 5 x 3 paper matrix:

- `marl_ppo_monolithic_winterwind.json`: one-agent four-hand PPO baseline;
- `marl_winterwind_ippo_obs_noise_gaussian_005.json`: IPPO observation-noise
  comparison;
- `pianosonata_no30_fourhand_ma_duet.json`: alternate-song four-hand example.
